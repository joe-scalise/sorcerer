# Sorcerer Promo Video Specification

**Goal:** Create a 45-second high-energy product hype video for Twitter, Reddit, and the Homepage.
**Core Message:** Sorcerer is the mission control for AI-first development—Direct, don't type.

---

## 1. Technical Stack (Recommended)
*   **Recording/Editing:** [Screen Studio](https://www.screen.studio/) (Industry standard for smooth zooms and cursor following).
*   **Voiceover:** [ElevenLabs](https://elevenlabs.io/) (Voice: "Adam" or "Josh" - Professional Narrator).
*   **Audio:** Minimal Tech House / Dark Cyberpunk Ambient (124 BPM).
*   **Theme:** Sorcerer "Catppuccin Mocha" or "Nord" (High contrast for video).

---

## 2. The 45-Second Script

| Time | Visual (Action) | Audio (Voiceover) |

## 3. Visual & Audio Guidelines

### The "AI Aesthetic"
*   **UI Scaling:** Record at 1080p but set Sorcerer's UI scale to 125% or 150% for mobile readability.
*   **Cursor Smoothing:** (Screen Studio feature) Ensure cursor movements are slow, deliberate, and perfectly linear.
*   **The "Briefing" Filter:** Apply a subtle low-pass (muffled) filter to the background music when the Briefing Panel is open to emphasize the text.
*   **Sound Effects:** Add subtle "pop" sounds when agents appear and "typing" sounds (low volume) when the AI streams.

### Key Scenes to Capture
1.  **Orchestration:** Show 3 active sessions in a split view—all "alive" and working.
2.  **Safety:** Show the 'Secure API Storage' in settings to reassure users about key handling.
3.  **Isolation:** Clearly show the 'Branch' and 'Worktree' labels in the Agent Tree to explain the value prop.
4.  **Clarity:** The AI Briefing section should be the slowest part of the video—let the user read the text.
