# Sorcerer v1.8.1

Released: 2026-09-18

## Highlights

- Download desktop updates in the background on Windows and Linux AppImage installations, then choose when to restart and install.
- Review release notes, download progress, installed and available versions, and update errors without leaving Sorcerer.
- Check for updates immediately from Settings, with separate preferences for automatic checks and downloads.

## Fixes and polish

- Save pending note drafts in every window before update installation; failed saves or unresponsive windows block the restart.
- Wait for terminal exits and session persistence before handing off to the installer, and prevent scheduled agents from starting during shutdown.
- Keep downloaded updates ready across transient failures and provide explicit retry actions.
- Validate update-feed versions, filenames, sizes, and SHA-512 hashes before staging release downloads.

## Notes

- Includes all changes since `v1.8.0`. Existing installations need one manual upgrade to this version to acquire managed updating.
- Updates never install automatically on quit. Restart and installation require your confirmation and stop running terminals and agents.
- macOS and development installations use manual downloads. Managed macOS updates remain disabled until signing and suitable update payloads are configured.
- Windows builds remain unsigned. Download integrity checks do not establish a verified publisher identity.
- Close Sorcerer and back up `~/.sorcerer` before upgrading. Avoid running development and installed copies simultaneously against the shared data directory.
