# Sorcerer v1.11.0

Released: 2026-10-28

## Highlights

- Capture personal notes, ideas, and to-dos in a resizable inbox, with project labels, pinning, ordering, archiving, deletion, and CSV export.
- Expand a session panel toward a chosen neighboring panel while preserving the rest of the layout.

## Fixes and polish

- Preserve session workspaces after landing, check prerequisites before stopping a session, and report remote push failures separately from successful local merges.
- Save session deletion before removing a workspace, preserve branches for recovery, and prevent the running app from deleting its own workspace.
- Prevent multiple updated Sorcerer instances from opening the shared database at the same time.
- Create new session worktrees from main or master instead of an unrelated checked-out feature branch.
- Restore database foreign-key enforcement after saving and improve Codex question keyboard controls.
- Update dependencies and repair Electron installation for development startup.

## Notes

- Includes changes since v1.10.0. Close any older Sorcerer instances before starting this version; older versions do not participate in the shared database lock.
- Landing retains the session, worktree, and branches for review; remove them explicitly when no longer needed.
- The release rehearsal produced an unsigned Windows installer and unsigned, unnotarized macOS builds. Verify signing status again before publishing the release.
