# Sorcerer v1.8.0

Released: 2026-09-18

## Highlights

- Pair the Android companion from desktop Settings with device-specific credentials, scoped remote access, and device revocation. Android APKs are distributed separately through `android-v*` releases.
- Protect saved projects, sessions, settings, and notes with atomic database replacement: a failed write preserves the previous complete database.
- Make everyday session management more dependable with safer worktree creation and landing, reliable note saving, and improved keyboard navigation.
- Update to Electron 42 with refreshed runtime and build dependencies.

## Fixes and polish

- Preserve existing workspace files and branches when a session name collides or Git cannot attach a worktree.
- Require a clean main/master checkout before landing; show unknown branch health as an error instead of success.
- Save pending notes when their panel closes, serialize overlapping saves, prevent save/delete races, and show retryable save errors.
- Sanitize rendered briefing and mission content, restrict external navigation to browser-safe links, and harden remote request handling.
- Keep focus inside dialogs, return focus to their opener, and let Escape close a dropdown without dismissing its parent dialog. Escape typed inside a terminal no longer closes its session.
- Keep creation dialogs open during pending operations, ignore stale project checks, preserve custom model input, and display failed actions clearly.
- Clarify unattended mode and its provider-specific permission and sandbox implications.
- Add project sidebar refresh, panel action menus, and spotlight controls.
- Validate release metadata and all expected installers before staging a GitHub draft; provide SHA-256 checksums and separate Intel and Apple Silicon Mac downloads.

## Notes

- Includes all changes since `v1.7.22`. Desktop and Android versions are released independently.
- Desktop downloads target Windows x64, macOS Intel x64 and Apple Silicon arm64, and Linux x64. Choose the download matching your operating system and architecture.
- Windows builds are unsigned. macOS signing and notarization depend on configured release credentials; do not assume a build is notarized unless its release verification confirms it.
- Close Sorcerer and back up `~/.sorcerer` before upgrading. Do not run development and installed copies simultaneously against the same data directory.
- Landing now requires you to commit or stash all project-repository changes, including untracked files, and check out main/master first.
- Failed note drafts remain available for retry in the current window; retry saving before quitting. Atomic database replacement protects against partial writes, but is not a substitute for backups.
- Remote access should remain on a trusted LAN or VPN. Android pairing does not make plain HTTP traffic encrypted.
