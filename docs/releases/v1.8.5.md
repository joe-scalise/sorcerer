# Sorcerer v1.8.5

Released: 2026-09-18

## Highlights

- **A quieter sidebar.** A compact New session action and on-demand search give Projects more room. Open search with its icon or **Ctrl+K**, including when the sidebar is collapsed or hidden.
- **A new pixel robot identity.** The app bar and desktop icon now share an amber robot with a face that fades into pixels.

## Fixes and polish

- Keep active search filters visible, and let Escape clear the query before dismissing search.
- Keep Add project available when search returns no results.
- Refine narrow and collapsed sidebar layouts, including when standalone Agents are enabled.
- Simplify the downloaded-update banner by removing its extra warning sentence. The restart-and-install confirmation remains in place.

## Notes

- Includes all changes since `v1.8.4`.
- Windows and Linux AppImage support automatic update downloads and notify you in the sidebar when an update is ready to install. macOS uses manual DMG downloads.
- Windows builds remain unsigned. Automated packaging and app smoke checks cover all four desktop targets; interactive installer/upgrade testing was not repeated for this patch.
