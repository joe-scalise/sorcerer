# Sorcerer v1.9.0

Released: 2026-09-18

## Highlights

- **A clean lightning bolt identity.** The app bar and desktop icon now use a simple, solid bolt, replacing the pixel robot introduced in v1.8.5.

## Fixes and polish

- Keep the desktop icon amber on a dark rounded tile, while the app-bar mark follows the selected theme accent.
- Smooth the bolt's diagonal edges and regenerate the Windows, macOS, and Linux icon assets from the same vector source.

## Notes

- Includes all changes since `v1.8.5`, released as a minor version at the maintainer's request.
- Existing sessions, projects, and settings remain compatible; no data migration is required.
- Windows and Linux AppImage support automatic update downloads and notify you in the sidebar when ready to install. macOS uses manual DMG downloads.
- Windows builds remain unsigned. Automated packaging and app smoke checks cover all four desktop targets; interactive installer/upgrade testing was not repeated for this release.
