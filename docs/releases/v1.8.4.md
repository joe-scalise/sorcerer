# Sorcerer v1.8.4

Released: 2026-09-18

## Highlights

- **Projects is now the default workspace.** Standalone Agents are an optional experimental feature, disabled by default for both new and existing installations.
- Re-enable standalone Agents in **Settings → General → Experimental features → Enable standalone Agents**, then quit and reopen Sorcerer.

## Fixes and polish

- Hide Agent creation, sidebar sections, search/navigation entries, orphan recovery, and Agent briefing content when disabled.
- Pause Agent startup and scheduled runs while disabled, including launches through remote clients.
- Remove unavailable Agent panes from restored layouts so Project sessions keep the available space.
- Keep preference changes pending until restart so current work does not disappear mid-session.

## Notes

- Includes all changes since `v1.8.3`.
- Agent code, definitions, groups, notes, history, workspaces, and schedules are retained. Re-enabling the feature resumes configured startup and scheduled runs. Previously open Agent panes are closed from the restored workspace; open them again from the sidebar after enabling.
- Coding-agent sessions, provider subagents, teams, and terminals within Projects remain available.
- Windows and Linux AppImage support managed downloads. Installation requires your confirmation. macOS uses manual downloads; Windows builds remain unsigned.
