# Sorcerer v1.8.2

Released: 2026-09-18

## Highlights

- Keep a direct link to the latest release available in update controls, including when an update check fails.

## Fixes and polish

- Show the target version in the titlebar's “Update ready” badge so you can see which version is waiting to install.

## Notes

- Includes all changes since `v1.8.1`.
- Windows and Linux AppImage installations on v1.8.1 can download this release through Settings → General → Check now. Choose Restart and install when your work is ready; running terminals and agents will stop.
- macOS uses manual downloads. Windows builds remain unsigned.
- Installations older than v1.8.1 need a manual upgrade to acquire managed updating.
