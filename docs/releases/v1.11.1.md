# Sorcerer v1.11.1

Released: 2026-10-29

## Highlights

- Run the Linux AppImage on Arch Linux and Omarchy without installing the separate `fuse2` dependency.

## Fixes and polish

- Bundle the static AppImage runtime instead of relying on the system's legacy FUSE2 library.
- Check the downloadable AppImage in Linux release CI with the system FUSE2 library removed.
- Document Linux first-launch steps and application-launcher behavior.

## Notes

- Includes changes since v1.11.0. Download the new AppImage to receive the runtime fix; previously downloaded files still use the old runtime.
- The AppImage still needs executable permission before first launch. This release does not include a native Arch package.
- Windows and macOS packaging is unchanged; Windows builds are unsigned and macOS builds are unsigned and unnotarized.
