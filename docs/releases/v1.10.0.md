# Sorcerer v1.10.0

Released: 2026-10-15

## Highlights

- Add GitHub Copilot CLI as a provider for Project sessions and experimental standalone Agents, including scheduled missions.
- Resume pinned Copilot conversations safely, restart with independent histories, and import existing local Copilot conversations.

## Fixes and polish

- Detect Copilot on PATH and in standard WinGet, Homebrew and npm locations, with safe Windows npm launching and legacy/current CLI flag detection.
- Support Copilot's native model selection, custom model overrides, unattended permissions and MCP configuration. Keep unsupported appended system prompts unavailable in the Agent dialog.
- Refresh an older provider registry automatically so new providers appear after upgrading, preserving saved provider preferences.
- Show provider-native session identity in diagnostics and validate the saved folder before resuming.
- Fix discovery and validation of Codex editor-origin conversations, show custom Codex conversation names, and avoid hiding older conversations behind global result limits.
- Update provider implementation and setup documentation.

## Notes

- Includes all changes since `v1.9.1`. Copilot CLI must be installed and authenticated separately; detection does not prove account/model entitlement. Keep the CLI current and use `/model` to select models available to your account.
- Copilot uses its own CLI/account default unless you set a model override. Its unattended toggle maps to `--allow-all`; folder trust and native permission policy remain owned by Copilot.
- Adds a nullable provider session ID to experimental Agent records. Existing projects, sessions, settings and Agent definitions remain compatible.
- Windows and Linux AppImage support managed updates; macOS uses manual DMG downloads.
- Windows builds remain unsigned. Automated packaging and app smoke checks cover all four targets. Isolated Windows Copilot CLI startup/resume and a live response were verified; interactive installer/upgrade testing across all platforms was not repeated.
