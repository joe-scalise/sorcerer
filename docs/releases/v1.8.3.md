# Sorcerer v1.8.3

Released: 2026-09-18

## Highlights

- See update download progress and a persistent **Restart and install** notice beside your profile and settings in the sidebar footer.

## Fixes and polish

- Keep update details accessible when the sidebar is collapsed, with a labeled update indicator.
- Show restart failures directly in the footer and disable the install action while preparing to restart.
- Clarify the automatic-download setting and where to find the restart notice.

## Notes

- Includes all changes since `v1.8.2`.
- Automatic checks and background downloads remain enabled by default on supported Windows and Linux AppImage installations. Checks run shortly after launch and every two hours; existing opt-outs remain respected.
- Installation still requires your confirmation. Running terminals and agents stop after notes and session state are saved.
- The new footer notice becomes available after installing this version. macOS uses manual downloads. Windows builds remain unsigned.
