# Sorcerer v1.9.1

Released: 2026-10-13

## Highlights

- Fix recurring terminal flicker in pop-out windows by preserving the terminal during session metadata refreshes.

## Fixes and polish

- Avoid replaying scrollback and stealing terminal focus on each pop-out refresh.
- Cancel pending terminal focus and resize work, and ignore late initialization results after a pop-out terminal closes.
- Center the automatic-update status text in the sidebar footer.
- Add regression coverage for terminal lifetime, current exit callbacks, and delayed initialization cleanup.

## Notes

- Includes all changes since `v1.9.0`; no data migration is required.
- Includes the repository's secret-free AetherCI setup manifest. AetherCI connection setup and event verification remain pending.
- Windows and Linux AppImage support automatic updates. macOS uses manual DMG downloads.
- Windows builds remain unsigned. Release validation includes automated packaging and app smoke checks; interactive installer/upgrade testing was not repeated for this release.
