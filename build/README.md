# Sorcerer app identity

`mark.svg` is the shared lightning bolt artwork: one solid silhouette with clean
diagonal edges. The app bar uses it as a CSS mask and follows the selected theme
accent; desktop icons use amber on a dark rounded tile.

Run `npm run icons:generate` after editing the mark. The generator uses the
project's Electron dependency in an isolated, hidden window and produces:

- `icon.svg`: amber mark on a dark rounded tile.
- `icon.png`: 512px Linux icon.
- `icon-1024.png`: source for the macOS icon set generated by the release workflow.
- `icon.ico`: Windows icon with 16, 24, 32, 48, 64, 128, and 256px entries.

Commit the generated assets alongside the source. Icon changes reach installed
copies in the next packaged release; the installed operating system icon is not
changed by editing the development checkout.
